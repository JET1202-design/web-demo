# Design rules

These rules apply to every page in this project.

- Typography: Fraunces for headlines, Source Sans 3 for body text. Never use Inter, Roboto, Arial, or system UI fonts.
- Color: ink #1C1917, paper #F4EFE6, accent rust #9A3412, rule line #D6C7B2. No purple-on-white gradients. No text gradients.
- Layout: left-aligned hero, not centered. No three equal feature cards in a row. No pill badges above the headline.
- Social proof: no five-star bars, fake testimonials, invented logos, or made-up client names.
- Copy: use the text in copy.md exactly. Do not rewrite, shorten, or "improve" it.
- Motion: one small idea at most, and honor prefers-reduced-motion.
- Tokens: put colors, type, and spacing in one place and reuse them. Do not invent a second palette mid-page.
- Keep this file short. Do not dump a full design system, a component library, or a QA script here.

# Publish rules

These notes are added to the existing design rules. Do not delete or replace the design rules already in this file.

- The brief in copy.md is locked. Do not rewrite, shorten, or "improve" it.
- The design rules already present in this file still apply.
- A local preview (including a desktop preview pane or localhost) is only a preview. It is not a live site.
- We call the site live only when a public URL opens in a browser.
- Keep index.html at the publish root.
- Do not write outside this practice folder.
- Do not buy a custom domain in this lesson.
